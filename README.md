# Build4Venezuela · Presentación

Presentación (slide deck) de **Build4Venezuela**, la hackathon humanitaria global para construir herramientas tech para Venezuela.

Un solo archivo HTML autónomo, navegable **solo con las flechas** (`←` / `→`), con la marca oficial: fondo negro, amarillo `#ffd83d`, cyan `#16c7e8`, tipografía *Input Mono Narrow*.

## Uso

Abre `index.html` en cualquier navegador.

- `←` / `→` (también `↑` `↓`, espacio, PageUp/Down) — navegar
- `Home` / `End` — primer / último slide
